Insert Bundle Unbundle

把选中的多条 wire 按位置自上而下 Bundle 成一个 cluster，再立即 Unbundle，把每个元素接回原来的源端子与下游端子。过程结束后数据流与改动前一致，只是中间多了一对 Bundle / Unbundle。

限制

  • 每根选中的 wire 只能有一个下游端子（无分叉）。
  • 选中对象不是全为 wire、wire 少于 2 根、或存在分叉时：返回错误（code = 1，source = Bundle Unbundle aborted），并放弃改动。

端子

连接器板为 4-2-2-4（pattern 4815），已按 NI 风格指南分配：输入在左、输出在右、错误端子在下方两角。

端子conIdx类型说明
QD Launch VI Ref11VI 引用，输入QuickDrop 启动所在的 VI；取它的 Block Diagram 的 Selection List[]。正常使用时接模板的 QD Launch VI Ref。
Diagnostic VI Path10字符串，输入留空即按选区工作。给路径时改为打开该 VI，对本框图内所有 wire 操作，结束时保存该 VI（测试与批处理用）。
error in (no error)8错误簇，输入接模板的 error in (no error)。
changes made?3布尔，输出是否实际改动了框图。
error out0错误簇，输出接模板的 error out。

在 QuickDrop 插件模板中接入

  1. 用 NEVSTOP_QuickDrop/QuickDrop Plugin Template.vit 新建插件 VI。
  2. 在框图里放置本 VI（函数选板 → Select a VI…）。
  3. 连 QD Launch VI Ref → 本 VI 的 QD Launch VI Ref；连 error in (no error) → 本 VI 的 error in；本 VI 的 error out → 模板的 error out。
  4. Diagnostic VI Path 留空；changes made? 可接可不接。
  5. 在插件 VI 的描述里加一行 Default Shortcut - [X]（X 为想要的快捷键字母）。
本 VI 不开启 Undo 事务，撤销由调用方（插件模板 / 管理器）负责；本 VI 返回错误时应让事务失败，避免留下半成品改动。

行为

  • 线序：按每根 wire 的 Master Bounds Rect.Top 自上而下排序，位置相同的按下标先后。
  • 新节点位置：以最上方那根线为基准，Bundle 在其右侧 60 像素，Unbundle 在其右侧 160 像素；cluster 连线在两者之间。
  • cluster 元素顺序与原始线的上下顺序一致，元素名取自源控件名。
  • 原有 wire 被删除后按“源端子 → Bundle 输入 i”与“Unbundle 输出 i → 原下游端子”重新连线。

验证记录

  • 三根互相独立的数据线（double / string / bool）：插入成功，changes made? = TRUE，无错误；导出目标 VI 可见源控件与 Bundle 元素一一对应、Unbundle 输出接回原指示器，上下顺序保持。
  • 存在分叉的线（一个源接两个下游）：返回 code = 1，changes made? = FALSE，目标 VI 未被改动。
